# Map data

Drop a real China province GeoJSON here as `china-provinces.geojson` and the globe
will render province borders as dotted outlines automatically (no rebuild needed).

Requirements:
- GeoJSON, WGS84 (lng, lat) coordinates.
- Province-level features (`Polygon` or `MultiPolygon`).

Sources: DataV.GeoAtlas (aliyun) or Natural Earth both work. Replace this empty
placeholder file with the real one.
